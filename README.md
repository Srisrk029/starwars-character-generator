# Star Wars Character Generator

## Description
A web application that fetches random Star Wars character details using a public API and displays name, species, homeworld, and image dynamically.

## Features
- Random character generator
- API integration using jQuery
- Dynamic DOM updates
- Responsive UI

## Tech Stack
HTML, CSS, JavaScript, jQuery, REST API

## How to Run
1. Open index.html in a browser
2. Click "Generate Character" button to fetch a random character

## Future Improvements
- Replace jQuery with vanilla JavaScript or React
- Add loading animation and error handling
- Display more character details
